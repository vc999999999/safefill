## 3 分钟 Demo 建议

下表是待录制脚本，不是已经录制完成的证据。统一使用合成姓名、工号、证件信息和图片；敏感操作在本人终端完成，示例中也不要把密码交给 Agent。

| 时间 | 画面 | 要让评委看到的事实 |
|---|---|---|
| 00:00–00:20 | 用合成共享明细表演示“填写时看到了别人资料”；给出本次收集需求 | 场景痛点具体，最终目标是收齐后交付 Excel |
| 00:20–00:45 | 在选定比赛 Agent 工具中调用收集者 Skill；展示用途、字段、名单、期限和生成产物 | Agent 能组织任务；公共模板与私人凭据分开发放 |
| 00:45–01:15 | 切到填写端，inspect 模板；本人终端解锁合成保险柜，查看仅匹配本次字段的结果并确认 | 填写者 Skill 有独立角色；资料复用和本人确认能实际工作 |
| 01:15–01:35 | 交回 .yintian；Agent ingest/status；重复导入同一文件 | 群里流转的是加密提交；重复收件不重复计数 |
| 01:35–02:10 | 展示预先准备的合成 OCR 冲突；本地窗口查看证据、逐项确认或退回 | 错误有处理路径；不能用人工确认跳过必填、身份或告知校验 |
| 02:10–02:35 | 再提交新版本，展示最新版本与最近通过记录；本地导出 Excel | 新提交不会被旧通过掩盖；HR 最终获得复核后的结构化结果 |
| 02:35–03:00 | 展示架构、现有测试记录及该机器的实际模型执行设备 | 软件证据、指定平台演示和硬件数据分别陈述 |

建议开场口播：“HR 只想把资料收齐，员工却可能在填表时看到所有同事的信息。隐填把这件事拆给两个 Skill：公共模板统一发，个人资料本地填，交回密文，最后由授权 HR 得到 Excel。”
