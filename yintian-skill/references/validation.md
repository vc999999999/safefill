# 3.5.0 验证记录 · 2026-09-08

## 本次交付

默认安装移除硬件 OCR 强制依赖。附件配置新增 auto/local/agent/manual；旧模板保持 local。宿主 Agent 只对本人授权的原件生成受约束候选，无独立模型 API 或 API Key。候选随提交一起加密，HR 本地复核后才允许导出。

Prompt 负责场景、本人授权与宿主识别；Python 负责候选与任务/模板/附件绑定、确认、验证、加密、版本、审计及 Excel。收集者与 MCP 未获得新的解密或人工放行入口。

## 已完成的实际链路

环境：macOS arm64，Python 3.11.15；没有安装 RapidOCR/OpenVINO，没有配置模型 API。所有人员、资料和密码均为合成测试数据。交互命令由隔离测试驱动器经真实 PTY 执行，未保存终端明文或密码转录。

| 环节 | 实际结果 |
|---|---|

| 个人保险柜 | 真实 vault-init 录入并加密；额外保存一个本次模板不要求的备注 |

Tk 图片/PDF 组件测试另覆盖两页 PDF 和五分钟空闲关闭。测试验证 300000ms 定时配置并将等待加速至 120ms，未实际等待五分钟。窗口交互由合成测试脚本触发真实控件，不属于真实人类可用性评测。

浏览器的 Page.setDownloadBehavior 未改变 ego 的默认下载目录；测试按实际下载文件名定位、校验摘要，再复制至隔离工作区，没有用内存 Blob 代替下载。
