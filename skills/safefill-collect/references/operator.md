# 操作边界

默认开放流程不要求 HR 或员工运行终端。Skill 中出现的命令是 Agent 的内部执行入口，不应原样交给普通用户。

## 默认开放流程

1. HR 在对话中说明用途、字段、必填性、截止时间和联系人。
2. Agent 生成 `REQUEST.yintian-request` 机器请求包；HR 只负责原样转发，不打开或改造成网页表单。
3. 员工 Agent 直接读取请求包、解释告知、一次问齐缺项并生成 `姓名-短码.yintian`；员工本人发送给 HR。
4. HR 指出回执目录和输出位置，Agent 一次完成收件、校验、解密、Excel 与附件目录导出。

更正时员工必须把本人上一次 `.yintian` 一并交给填写 Agent。Agent 使用 `submit --previous` 生成同一随机回执编号的新版本。无法取得旧回执时不要按姓名覆盖，联系 HR 处理重复记录。

## 异常

- `OUTPUT_EXISTS`：选择新输出名，绝不覆盖已有 Excel 或附件目录。
- `LOCAL_KEY_UNAVAILABLE`：任务目录外的本地密钥缺失或权限不安全；从加密任务交接包恢复，不能绕过。
- `needs_review` / `invalid`：不混入 Excel；报告排除数和固定错误类别，不把其他人的明文贴入聊天。
- `TASK_BUSY`：等待当前操作完成，不删除锁文件。
- 到期任务停止收件、复核和导出。

## 强认证兼容模式

只有 HR 明确要求预先限定提交者时，才启用 `group`：需要 `employee_id,name` 名单，并把个人凭据私下发给对应员工。该模式的密码、人工证据裁定、明文白名单导出和清理命令属于授权操作员的兼容入口，不是默认 HR 流程；Agent 不代替操作员输入秘密或人工放行。
