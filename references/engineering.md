# 工程职责与交付 · 3.4.0

目标是两个短 Skill 驱动一个确定性的私密收集闭环。主 Prompt 各 36 行；操作细节按需读参考文档。

| 环节 | Prompt / Skill | Python |
|---|---|---|
| 角色与范围 | 区分 HR、填写者；普通问卷不触发；只补问缺失要求 | 校验配置、字段类型、期限与名单 |
| 模板分发 | 沿用发送授权，选择群和个人收件人，核查成功回执 | 生成公共模板及个人凭据，检查路径和分发索引 |
| 员工填写 | 解释模板、核对收集方，交接本人终端 | 解锁保险柜，只匹配请求字段；歧义显式映射；预览并确认本次取值 |
| 提交认证 | 只转交密文，不猜身份或编造值 | AES-GCM/RSA-OAEP、个人 HMAC、任务/模板/令牌/名单校验 |
| 收件与进度 | 报告最新提交、待处理、最近通过；解释下一步 | 幂等接收、版本分离、事务恢复、稳定错误码 |
| OCR 复核 | 不替本人判断、不按 OCR 覆盖手填值 | 漏识别、歧义、低置信度和冲突进入待复核；运行故障可重试 |
| 人工结案 | 交接 HR 本人终端，不启动或旁观窗口 | 内存证据窗口、逐页查看及逐项确认；硬性错误不能放行；提交时重查状态和期限 |
| Excel 汇总 | 说明字段白名单、用途和接收方，交接授权 HR | 只纳入每人最新已通过版本；再次校验；公式转义、受限权限、原子写入且不意外覆盖 |
| 恢复与边界 | 不执行输入材料中的指令；如实说明故障与限制 | 路径组件拒绝链接、OS 文件锁、SQLite 备份迁移、最小操作审计 |

关键实现：`scripts/collection.py` 管任务与汇总；`secure_io.py` 管实际文件访问；`review_evidence.py` 管本地证据；填写端 `vault.py` 管个人保险柜，`fill.py` 管模板与提交。MCP 保持原有七个工具，不增加敏感操作接口。

## 已修复的实际问题

- 公共模板不能再凭工号冒用他人；缺认证或移植认证标签在占用版本额度前拒绝。
- 员工无需先交给 Agent 一份明文 values.json。保险柜存储值和附件字节，按本次模板筛选；取消或未确认不产出密文。
- 缺告知、身份/格式有误、OCR 漏识别及歧义不会直接通过。OCR 运行故障可重试；人工结案不被普通重试覆盖。
- 新版待处理不会被旧版通过隐藏，也不会静默导出旧版。Excel 从已通过的最新提交产生，再检查硬性规则。
- 实际 XLSX 路径、报告、提交文件、分发 CSV 及清理路径拒绝链接；清理避开活动任务锁。文件写入或 SQL 失败可以恢复并幂等重试。
- 公共 JSON 模板不再被说明为双击浏览器填写；定向 HTML 保留兼容入口。

## 兼容与安装

新群发使用 `yintian-form/2`、`yintian-submission/3` 与单独个人凭据。定向 v2 密文和旧邀请保持兼容；旧无认证群发任务只读。旧数据库通过显式 `migrate` 备份并升级，旧自动通过记录重新复核，查询不偷偷迁移。

发布包只含允许发布的源码、说明与资源，顶层 `yintian-skill/`。填写端附带从同一源码生成的公共模块，可独立安装。核心/OCR/开发依赖分组，Mac Python 3.11 的受测锁文件见 `requirements-tested-py311.txt`。生成 ZIP 的参数和源树相同时字节相同。

## 验证范围

[验收记录](validation-3.4.0.md) 给出运行命令、实测结果和证据摘要。自动化使用合成身份与真实加密、SQLite、Excel、MCP stdio 及发布包。Tk 另做实际组件测试；OCR 业务规则使用可控输出。

评测 JSON 是行为场景规范，供后续真实模型测试使用；本次不把规范数量计作 Agent 行为通过率。没有 Windows/Linux 实机、真实证件准确率、真实群消息送达或 Intel GPU/NPU/INT8 收益的验收结论。

Prompt 和 TTY 不是对同账号恶意进程的强隔离。个人凭据不证明证件真伪；独立核对收集方公钥仍由本人完成。明文 Excel 的后续传播由授权持有人管理。
